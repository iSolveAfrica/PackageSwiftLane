# Map data

| File | What | Source and licence |
| --- | --- | --- |
| `world-dots.svg` | Dotted world map for the tracking console | see `views/sl/data/track_console.php` |
| `ghana-map.json` | Outline of Ghana, the 16 regions with their capitals, projection | Outline from Natural Earth (public domain) via the `@geo-maps/countries-land-1km` npm package (MIT). Region capitals entered by hand. |
| `ghana-places.json` | Place name → `[region, lat, lon]` used to put recipient cities on the Ghana map | Wikidata via the `@geomelon/ghana` npm package (CC0 1.0), plus common Accra, Tema and Kumasi neighbourhoods entered by hand. Coordinates are `null` where the source was ambiguous; those places are drawn near their region capital. |

The two Ghana files are generated by `scripts/build_ghana_map.py <countries-land-1km map.geo.json> <@geomelon/ghana data.json> assets/swiftlane/maps`.
